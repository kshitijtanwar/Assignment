# Authentication Screens

This repository contains the login and signup screens built using React.js and Tailwind CSS. These screens are designed to provide a simple, user-friendly interface for user authentication.

## Features

- **Login Screen:** Allows users to log in with their credentials.
- **Signup Screen:** Enables new users to create an account.
- **Mobile Design:** Optimized for mobile using Tailwind CSS.

## Tech Stack

- **Vite:** Build tool used for faster and leaner development.
- **React.js:** Frontend framework used to build the user interface.
- **Tailwind v4.0:** Utility-first CSS framework for styling.
- **Framer Motion:** Animation library for smooth, interactive UI animations.


## Prerequisites

Before running this project, ensure you have the following installed:

- [Node.js](https://nodejs.org/en/) (v14.x or higher)
- [npm](https://www.npmjs.com/get-npm) (v6.x or higher)
